# wrist-arcana-android

A native **Wear OS / Android** port of the watchOS app **Wrist Arcana** — a fully
offline tarot-reading app for smartwatches (Samsung Galaxy Watch, Pixel Watch,
and other Wear OS 4+ devices).

Draw a cryptographically fair card from the 78-card Rider–Waite deck, see its art
and meaning, keep a persistent history of your readings with notes, and browse
every card's upright/reversed meanings in a reference library — all with zero
network access.

## Status

Scaffold + plan stage. The complete, authoritative porting plan is in
[`plans/SPEC.md`](plans/SPEC.md). Implementation is driven issue-by-issue by the
**Ralph loop** (see [`CLAUDE.md`](CLAUDE.md) → "The Ralph Loop"), with the
backlog generated by running the `spec-decomposition` ("decompose") skill against
the SPEC.

## Tech stack

- Kotlin + **Jetpack Compose for Wear OS**
- **Room** for persistence, coroutines + `StateFlow`, MVVM with interface DI
- kotlinx.serialization (bundled `DecksData.json`, reused from the original)
- `SecureRandom` for fair draws
- Gradle (Kotlin DSL); ktlint + detekt + Android Lint; JUnit5 + Compose UI tests; Kover coverage

## Getting started

```bash
pre-commit install          # generic hooks + detect-secrets + shellcheck
./scripts/check-all.sh      # quality gate (guarded until the Gradle module lands)
```

See [`CLAUDE.md`](CLAUDE.md) for the full workflow, quality gates, and the Ralph
